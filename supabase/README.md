# LifePass AI — Supabase Backend Foundation

Supabase configuration, SQL migrations, seed data, and Edge Functions directory.

## Directory Layout

- `migrations/`: Versioned PostgreSQL database migrations (Phase 1+).
- `functions/`: Supabase Edge Functions (Deno/TypeScript).
- `seed/`: Seed data for development and testing.
- `config.toml`: Supabase CLI configuration.
